# Emergency Route Optimizer

## Project Overview
Emergency Route Optimizer is a Java-based project designed to find the shortest path between two locations using Dijkstra's Algorithm.

The project helps identify an efficient route between a selected source and destination.

## Technologies Used
- Java
- MySQL
- JDBC
- Dijkstra's Algorithm

## Features
- Select source and destination locations.
- Find the shortest route.
- Calculate the minimum distance.
- Display the optimized route.
- Connect Java application with MySQL database using JDBC.

## Algorithm Used
**Dijkstra's Algorithm**

Dijkstra's Algorithm is used to find the shortest path between a source location and other locations in a weighted graph.

## Database
MySQL is used to store location and route-related information. JDBC is used to establish connectivity between Java and MySQL.

## Project Objective
The main objective of this project is to understand graph algorithms and implement shortest-path finding using Java and database connectivity.
